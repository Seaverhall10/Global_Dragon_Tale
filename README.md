# Global Dragon Tale Project

Comparative research desk for **global serpent and dragon symbolism** — stories, tales, history, and motifs across cultures.

## Scope

- Chaoskampf and dragon-slayer patterns
- Biblical and Second Temple threads (Genesis serpent, Leviathan, Revelation dragon) as *one family among many*
- Ancient Near East (Tiamat, Lotan, Apophis, and kin)
- Indo-European, East Asian, Mesoamerican, African, and other attested traditions
- Honest contested readings; **no invented name-bridges** without labeled hypothesis + primary citation

## Not this project

- Cutroom / private media
- Ancient Texts app product work (Bible chapters feed *into* this desk; this desk does not own Hosting deploys)
- Looking Beyond personal name dossiers for living people
